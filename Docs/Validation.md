- 最终 49 项自动测试通过，包括 6000 项取消的写入次数上限、图片处理积压时取消、取消绕过请求互斥锁、依赖查询缓存、分帧准备取消、检查点发布后的中断恢复与外部历史更新。
- 实际 5967 项选择在准备阶段取消耗时 0.108 秒；子编辑器启动阶段取消耗时 0.416 秒。已核验子进程结束，主 UE 编辑器保持运行。
- 旧批次记录压缩为约 5.99 MB，历史索引约 8.7 KB。轻量进度 HTTP 响应约 351 字节、2 ms；历史列表约 3.1 MB、120 ms，读取不重写索引。此数据包含既有历史，后续新增批次会改变体积。
- 对同一组 24 个真实 Mesh / Skeletal Mesh / BP 进行两轮采集，均 24/24 成功，所有临时世界在卸载后为 0。准备阶段 0.95 / 0.89 秒，整批 106.83 / 101.27 秒，含 Worker 冷启动 50.66 / 45.67 秒及收尾。扣除 Worker 启动和配置准备后，吞吐约 2.31 / 2.28 秒每资产；不将样本吞吐视为全目录保证。
